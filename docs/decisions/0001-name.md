# 0001 · Name: fabric-weft

- **Status:** accepted, the user may veto (renaming is cheap until the first tool depends on it)
- **Date:** 2026-11-21 · **Proposed by:** Theo · **Objection:** Bruno

## Decision

The distribution is called **`fabric-weft`** and the import is **`fabric_weft`**.

In weaving, the *weft* is the thread that runs across the warp and turns loose
threads into cloth. This library does the same to Fabric Engine output: loose
lines of text in, structured records out.

## Why

- The user asked for something more creative than "fabric-engine-parser".
- `weft` alone is taken on PyPI. The internal mirror proxies PyPI, so a bare
  `weft` could install the wrong package. `fabric-weft` is free, and `fabric_weft`
  doesn't collide with the `fabric` SSH library.
- The project folder stays `fabric-engine-parser`; the GitHub repository can be named either way.

## Objection

*Bruno:* "A pun costs everyone who reads `import fabric_weft` for the first time a
second." Accepted. The README's first line says what it is.

## Rejected

`weft` (taken), `bobbin`, `selvedge`, `twill`, `spindle`, `unravel` (all taken on PyPI).
